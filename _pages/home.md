私たちは、**化学と情報科学**の交差点で研究を行うグループです。データ駆動型のアプローチを通じて、新しい分子と材料の発見と設計を加速することを目指し、**化学構造の情報を整理し世界中の人々がアクセスして使えるようにしていきます。**

### このホームページ以外で対外的に、研究室で発信をしているページは以下の通りです。

- [POCLab-web](https://github.com/poclab-web) - Github Organizationを使って、研究室で作成したプログラムを公開
- [POCLab-zenodo](https://zenodo.org/communities/poclab) - データやライブラリの配布場所として公開
- [Poclab Tech Blog](https://zenn.dev/p/poclab_techblog) - Zennというエンジニアのための情報共有コミュニティで、発信
- [ケモインフォマティクス✖️ハッカソン合宿](https://cheminformatics-hackathon.github.io/homepage/) - ハッカソンは、「ハック（Hack）」と「マラソン（Marathon）」を組み合わせた言葉で、限られた時間内にチームや個人でアイデアを出し合い、プログラムやサービスを一気に作り上げるイベントです。様々な大学の方々と横浜市上郷・森の家で夏に合宿として行なっています。
